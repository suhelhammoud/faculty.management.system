# Asset Inventory System

Inventory manages durable assets, employee and shared custody, Facilities room
locations, consumable stock, and transaction history. Employees can open **My Items**
to see their own current assignments. Operators can post movements and manage
storage. Removal proposals go through review and committee decision in the
workflow inbox.

Use Inventory [standalone](http://localhost:3008/inventory) or in the
[faculty shell](http://localhost:3000/inventory). Both support English and Arabic.
